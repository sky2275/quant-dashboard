# 双券商交割单 → 自动合并持仓

把两家券商的交割单 CSV 放进来，看板会在每次刷新时**自动合并两个账号**、算出每只股票的
持仓数量、成本价、盈亏，并在「⑤ 持仓复盘」模块按「银河 / 东财」分账号展示。

## 怎么放（半自动，每月/每周点一下）

1. 从两家券商客户端各导出一份**交割单**（CSV 或 Excel 都行：银河海王星多为 `.xls`，
   东财多为 `.xlsx`，直接导出原格式即可，**不用转成 CSV**）。
2. 把文件放进对应目录：银河的放 `data/statements/galaxy/`，东财的放 `data/statements/eastmoney/`。
   - 可放多个文件（按月份拆也行），会全部合并。
3. 提交并推送（`git push`），或等下一个定时刷新，或点一下 **Actions → 手动触发**。
4. 看板自动重建，持仓模块即显示双账号合并结果。

### 💡 更省事：桌面取件（推荐 Mac 用户）
券商导出的文件通常就在**桌面**上。本仓库附带一个小帮手，自动把桌面的交割单
搬进对应目录并推送：

```bash
# 在仓库目录下运行（终端里粘贴回车即可）
python3 scripts/pickup_statements.py
```

- 它会扫描桌面上的 `.xls / .xlsx / .csv`，按文件名自动判断是银河还是东财
  （判断不了会逐个问你选哪家）；
- 复制完成后会问你要不要推送，输入 `y` 就自动提交并触发看板更新；
- 想一步到位也可：`python3 scripts/pickup_statements.py --push`。

## 导出步骤

### 银河证券（电脑端）
登录「银河证券 海王星 / 双子星」交易软件 →
`查询` → `交割单`（或`历史成交`）→ 选择时间范围（建议选「全部」或近一年）→
点 `输出 / 导出` → 存为 **Excel(.xls)** 或 **CSV** 均可（银河 .xls 多为 GBK 编码，本系统已兼容）。

### 东方财富证券（电脑端）
登录「东方财富证券」电脑端 → `交易` → `查询` → `交割单 / 历史成交` →
选时间范围 → 右上角 `导出` → 存为 **Excel(.xlsx)** 或 **CSV** 均可。

> 手机端：两家 App 的「交易 → 查询 → 交割单」里一般也有「导出」入口，路径类似。

## 脱敏与安全
- **可以打码**：股东账号、姓名等隐私列删掉或涂黑都行。
- **必须保留**：证券代码、证券名称、买卖方向、成交数量、成交价格（或成交金额）、
  费用（佣金/印花税/过户费）。这几列是算成本与盈亏的依据。
- 交割单只含你自己的交易记录，不含密码；但仍是隐私文件，请勿公开发布仓库。

## 列名对不上怎么办
解析列名写在 `config/broker_maps.yaml`（银河 / 东财 各一组）。
若你导出的 CSV 列名和默认值不同，**告诉我实际列名**，我改映射；
或直接编辑 `config/broker_maps.yaml`（只改列名，不碰代码）。

## 计算口径
- 按「代码」聚合每笔买卖，还原当前持仓：**买入**累加数量并把(价格×数量+费用)计入成本；
  **卖出**按当前均价减少数量与成本。剩余数量 > 0 即为当前持仓，均价 = 剩余成本 / 剩余数量。
- 现价、RSI、MACD、量比、换手、主力净流入 仍由看板原有的腾讯/tushare 实时补充。
- 若某账号某只已清仓（数量归 0），不会出现在持仓里。
